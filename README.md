# Python Teasers

Python Teasers is a collection of small, focused Python exercises designed for
practice and deliberate learning. The goal is to help you strengthen your
Python fundamentals, identify gaps in your knowledge, and gradually progress
from beginner concepts to more advanced mastery.

This repository is most useful when you attempt each exercise on your own
before checking or changing the provided code.

## Practice levels

### 1. Beginner

Build confidence with variables, input and output, basic operators, conditionals,
and simple loops.

Suggested exercises:

- `simple-math.py`
- `value2.py`
- `call-me-baby.py`
- `sendittotheprinter.py`
- `click-button.py`

### 2. Intermediate

Practice control flow, data types, slicing, functions, and more complex
expressions.

Suggested exercises:

- `slice.py`
- `looploop.py`
- `while.py`
- `mulassignments.py`
- `great-divide.py`
- `divide-time.py`
- `tellmethefuture.py`

### 3. Advanced

Combine multiple concepts and reason about less obvious behavior, edge cases,
and Python subtleties.

Suggested exercises:

- `explanation.py`
- `not-type.py`
- `inside-job.py`
- `identify-crisis.py`
- `where-waldo.py`
- `reversed.py`
- `rounderound.py`

## How to practice

1. Choose an exercise from the list above.
2. Read the source code and predict the result before running it.
3. Run the exercise with Python:

   ```bash
   python filename.py
   ```

4. Change one line or value at a time.
5. Observe how the result changes and explain why.
6. Rewrite the exercise in a clearer or more efficient way.
7. Repeat the exercise later without looking at your previous solution.

To become more consistent, follow this cycle:

```text
Read -> Predict -> Run -> Experiment -> Explain -> Rewrite
```

## Learning tips

- Practice for 20–30 minutes several times a week.
- Understand the reason behind every result, not just the output.
- Use the Python documentation when a built-in function or behavior is unclear.
- Try to solve a problem in more than one way.
- Review earlier exercises after learning a new concept.
- Write comments or short notes only when they help explain an idea.

## Project structure

The exercises are standalone Python scripts stored in the repository root.
Each filename describes a small puzzle or theme. There is no required setup:
you can run individual scripts directly with Python.

Requirements:

- Python 3
- A terminal or Python-compatible editor

## Goal

The goal is not only to find the correct answer. It is to develop the habits of
a strong Python programmer: careful reading, clear reasoning, experimentation,
debugging, and continuous improvement.
